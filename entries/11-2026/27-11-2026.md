### Database basics
- A table stores a set of things. Each row is one item and each column is one attribute of that item.
- Compared to a spreadsheet, a database handles much more data and many updates at once and finds records faster.
- A DBMS is the software for creating, reading, updating and deleting data (SQLite, MySQL and PostgreSQL are examples). SQL is the language, but every DBMS supports only part of the standard, so queries can need small changes when moving between systems.
- SQLite is lightweight and used in phones, desktop apps and websites.

### Querying
- `SELECT` picks columns (`*` means all of them) and `FROM` names the table. `LIMIT` caps the number of rows.
- `WHERE` filters rows with `=`, `!=` (or `<>`), `NOT`, `AND` and `OR`. Parentheses control the order of evaluation.
- Identifiers go in double quotes, strings in single quotes and numbers stay unquoted.
- `NULL` marks a missing value. It is tested with `IS NULL` and `IS NOT NULL`, never with `=`.
- `LIKE` matches patterns: `%` stands for any number of characters and `_` for exactly one. In SQLite `LIKE` ignores letter case while `=` does not.
- Ranges use `<`, `>`, `<=`, `>=` or `BETWEEN` (inclusive on both ends).
- `ORDER BY` sorts ascending by default. `DESC` reverses it and extra columns break ties.
- Aggregate functions collapse many rows into one value: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX` and `ROUND`. `AS` renames the result column and `COUNT(DISTINCT col)` counts unique values.

### Robot programming basics (PyBullet)
- A robot program can be a simple list of positions executed in order. Changing the list changes the motion.
- A fixed time per move does not guarantee the robot reaches the target, because the program does not check where the joint is.
- A loop repeats a motion, so a short program can describe a long, cyclic task. An endless loop has to be stopped from outside.
- A condition lets the program read the state of the robot and decide what to do next, for example when to reverse the direction.
- The target is what the program asks for, and the measured position is what the robot actually does. The difference between them is the control error.
- A list says what to do, a loop says how many times and a condition says when to change the behaviour. Together they allow more complex programs.

## What surprised me

- The `LIKE` operator is case insensitive in SQLite while the `=` operator is case sensitive. For example, `WHERE "title" LIKE 'pyre';` matches 'pyre', 'Pyre' and 'PYRE', but `WHERE "title" = 'pyre';` matches only the exact string 'pyre'. `LIKE` becomes really useful with wildcards: `%` matches any number of characters and `_` matches exactly one, so `WHERE "title" LIKE '%pyre%';` finds every title that contains "pyre".

### PyBullet: sequence, loop and condition

```python
import pybullet as p
import pybullet_data

p.connect(p.DIRECT)   # no window, enough for a quick test
p.setAdditionalSearchPath(pybullet_data.getDataPath())
robot = p.loadURDF("kuka_iiwa/model.urdf", useFixedBase=True)

joint_id = 2
positions = [0.5, -0.5, 1.0]        # sequence: the "program"

for target in positions:            # loop over the list
    for _ in range(480):            # 2 s per target (240 steps = 1 s)
        p.setJointMotorControl2(robot, joint_id, p.POSITION_CONTROL,
                                targetPosition=target, force=0.5)
        p.stepSimulation()

    position = p.getJointState(robot, joint_id)[0]   # measured state
    error = target - position
    if abs(error) > 0.01:           # condition: react to the state
        print(f"target {target}: not reached, error {error:.3f} rad")
    else:
        print(f"target {target}: reached")

p.disconnect()
```
