## What I learned

### Python and data
- Python environments: `venv`, `uv`, Python version pinning, Jupyter and Google Colab
- Python basics: lambda, `sorted` with `key`, classes and `self`, `try/except`, f-strings
- Files and paths: `os`, `zipfile`, relative paths
- NumPy: arrays, shapes `(rows, cols)`, `reshape`, `axis`, `dot`/`@`, `cumsum`/`prod`, random numbers, broadcasting
- Matplotlib: `plot`, `scatter`, `subplots`, `fig` vs `ax`, legends and titles
- Pandas: `Series`/`DataFrame`, `loc`/`iloc`, boolean masks, `isin`, `drop`/`dropna`/`fillna`, `concat`, `read_csv`
- Exploratory data analysis: `describe`, correlation, histograms, KDE, boxplots, bar plots
- NumPy vs pandas: when to use which

### Search algorithms
- States vs paths, the search tree
- BFS (queue) and DFS (stack), memory usage
- Cycle-safe DFS
- Greedy Best-First Search and why it can be suboptimal
- A*: `g(n)`, `h(n)`, `f(n) = g(n) + h(n)`
- Heuristics: admissibility and consistency, what overestimating does
- Grid heuristics: Manhattan and octile distance
- Maze pathfinding: diagonal moves, weighted cells, BFS vs A* compared

### Knowledge representation
- Choosing a representation: constraints, production rules, ontologies, frames
- Propositional logic and truth tables
- First-order logic
- Forward and backward chaining
- Open-world vs closed-world assumption
- Frames: slots, default values, inheritance
- Ontologies: classes, relations, axioms, consistency checking
- Fuzzy logic (`scikit-fuzzy`): membership functions (`trimf`), fuzzification, rules, defuzzification (centroid)
- Fuzzy control systems: `Antecedent`, `Consequent`, `Rule`, `ControlSystem`

### Robotics
- PyBullet basics: `connect` (GUI/DIRECT), `loadURDF`, `stepSimulation`, simulation loop timing
- URDF: links, joints, fixed base
- KUKA iiwa arm: 7 revolute joints, joint indices and axes
- Joint info and limits (`getJointInfo`)
- Joint state readout (`getJointState`): position, velocity, torque
- Position control (`setJointMotorControl2`, `POSITION_CONTROL`), `force` as a torque limit
- Feedback and control error, target sequences
- Gravity and motor strength
- Sensors: proprioceptive vs exteroceptive
- Debug visualizer: sliders, labels, wireframe, joint axes, preview panels
- ROS 2 Jazzy: nodes, topics, publisher/subscriber (`/chatter`, `std_msgs/String`), `ros2 topic hz`

### Machine learning
- What it means for a system to "learn" from data
- Linear classifier `y = w1x1 + w2x2 + b`, decision boundary
- Classification error and minimizing it
- Linearly vs non-linearly separable data (concentric circles)
- Training vs test error, overfitting and underfitting, generalization
- scikit-learn basics: `load_iris`, `LabelEncoder`, `shuffle`, features vs target
- Classifiers: Naive Bayes, Logistic Regression, Decision Tree, k-NN, SVM (RBF), Random Forest
- Model evaluation: cross-validation, hyperparameter tuning, confusion matrix, F1, ROC-AUC, threshold tuning, bootstrap intervals, majority baseline
- Neural networks: single neuron, weighted sum, bias, pre-activation
- Activation functions: ReLU, sigmoid, tanh, the dying ReLU problem
- Multi-layer networks: weight and bias shapes, forward pass, XOR
- Loss functions: MSE and binary cross-entropy, gradients
