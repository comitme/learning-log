## What I learned
- A neuron computes `z = w·x + b` and then `a = f(z)` -- one weight per input and one bias that works like a threshold.
- Without a nonlinear activation, stacked layers collapse into a single linear function, so a hidden layer would be useless.
- Shapes: X is (examples, features), W is (inputs, neurons) and b is (1, neurons). The architecture 2 -> 3 -> 1 says nothing about how many examples there are.
- Training is a loop: forward pass, loss, backward pass (gradients), update. Only the update step actually changes the weights.
- AND and OR can be solved by a single neuron, because one straight line separates the classes. XOR needs a hidden layer.
- Learning rate, number of hidden neurons, number of epochs and the loss function all change how fast (and whether) the network learns. It is best to change one thing at a time and compare the loss curves on one plot.
- With sklearn, `MLPClassifier.fit()` does the whole loop in one line, but I only understood what it hides after writing the loop by hand. The model should be evaluated on a test set.

## What surprised me
- Classification can be correct long before the loss is small -- in XOR all four outputs were on the right side of 0.5 after about 800 epochs, while the loss kept falling for thousands more.
- The same XOR code with 2 hidden neurons and `seed(0)` got stuck at a loss of about 0.13, while 3 neurons solved it. The result depends on the starting weights.
- A huge learning rate did not blow up the network. The sigmoid saturates, so it jumped around and got stuck on a plateau instead -- at lr = 100 the loss sat at 0.25 for roughly 2800 epochs before recovering.
- BCE trained much faster than MSE on XOR (all outputs within 0.1 of the target after about 650 epochs vs about 3900), because its gradient does not shrink with the sigmoid derivative.

## Where I got stuck
- Telling examples from features in the shapes -- for a long time I mixed up rows and columns, especially in a 2 -> 3 -> 1 network.
- Why `dW = X.T @ dz / m` has a transpose and where the gradient formulas come from.
- How the learning rate changes the step size, even on a simple parabola. It took a few numeric examples before it clicked.
- Small coding mistakes: a typo in a variable name (`inpt` instead of `X`) that silently used an old variable from another cell, and a `losses` list that was not reset, which glued several training runs into one plot.

## Code and notebooks
Training loop for the XOR network (2 -> 3 -> 1):

```python
for epoch in range(5000):
    a1 = sigmoid(X @ W1 + b1)                  # forward
    a2 = sigmoid(a1 @ W2 + b2)
    losses.append(np.mean((y - a2) ** 2))      # loss

    dz2 = (a2 - y) * sigmoid_derivative(a2)    # backward
    dz1 = (dz2 @ W2.T) * sigmoid_derivative(a1)
    dW2 = a1.T @ dz2 / len(X); db2 = dz2.mean(axis=0, keepdims=True)
    dW1 = X.T @ dz1 / len(X);  db1 = dz1.mean(axis=0, keepdims=True)

    W2 -= lr * dW2; b2 -= lr * db2             # update
    W1 -= lr * dW1; b1 -= lr * db1
```
